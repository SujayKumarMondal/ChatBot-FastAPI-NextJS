📖 About ChatPaat

ChatPaat is a full-stack AI chatbot designed to provide fast, intelligent conversations through a clean and responsive interface. It combines a modern React frontend with a FastAPI backend and Groq-powered AI.

✨ Key Features

🤖 AI Conversations

Intelligent responses powered by Groq's OpenAI GPT-OSS 20B model.

🔐 Secure Authentication

JWT authentication, secure password hashing and Google OAuth 2.0.

💬 Chat History

Conversations and messages are stored and available for later access.

👤 User Profiles

Profile management, password changes and profile image support.

📱 Responsive UI

Modern interface optimized for desktop, tablet and mobile devices.

🎨 Modern UX

Smooth animations, clean design and dark/light theme support.

🛠️ Technology Stack

Python FastAPI SQLAlchemy PostgreSQL React TypeScript Vite Tailwind CSS Groq AI JWT Google OAuth Alembic

🏗️ Architecture

Frontend

React + TypeScript + Vite with responsive components and client-side state management.

Backend

FastAPI REST APIs handling authentication, chat operations, profiles and AI requests.

Database

PostgreSQL with SQLAlchemy for users, conversations, messages and application data.

AI Layer

Groq API provides fast AI inference using OpenAI GPT-OSS 20B.
